When you need an app, not a website

Some tasks require an app installed on a device: a till that prints a fiscal receipt, a program that works without internet, or a tool that talks to a printer or scanner.

We build these apps with web technologies, packaged for Windows with Electron and for Android with Capacitor. That way the same foundation runs on a computer, tablet and phone.

Typical problems

  • POS software that doesn’t fit the process
  • Manual entry between the till and the system
  • Expensive licences for every workstation
  • An app that doesn’t work without internet
  • Different programs on phone and computer
  • Devices that don’t connect
