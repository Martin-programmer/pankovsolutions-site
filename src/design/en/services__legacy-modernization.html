When it’s time to modernise

Many companies work with programs written years ago: on old technologies, without documentation and often by someone who is no longer around. They work, until one day they stop.

Modernisation doesn’t mean throwing everything away. It means understanding what the old system does, keeping the data and logic that have value, and moving them onto a foundation that can be maintained and developed.

The risks of an old system

  • Nobody knows how it works
  • The author is no longer available
  • It only runs on one old computer
  • It can’t connect to anything
  • Security holes
  • Every change is a risk

How we approach it

The biggest risks in modernisation are losing data or stopping work. That’s why we plan the transition so that neither happens.

First we understand

We analyse the old system, the data and the processes before proposing anything.

A ready-made foundation when possible

Often the old program can be replaced with Odoo plus add-ons, instead of writing a new one from scratch.

Phased transition

We migrate module by module, and the old and new systems run in parallel for as long as needed.

Data verification

We reconcile the migrated data with the original before switching off the old system.

Documentation

The new system is documented, so you don’t depend on one person.

An honest assessment

Sometimes it is better to improve the old system. We will tell you.

Frequently asked questions

Can’t find an answer? Call +359 877 944 224.

Will we lose data?+

The whole point of the process is to lose nothing. Data is reconciled with the original, and the old system stays available until we are sure.

Will work stop?+

No. Both systems run in parallel until the team is used to the new one and it is confirmed that everything is fine.

We have no documentation for the old program. Is that a problem?+

That is the most common case. We analyse the database and the way the program is used to understand what it does.

A new system from scratch or a ready-made platform?+

It depends. Often Odoo with add-ons covers the needs faster and more cheaply. When the process is very specific, we write a new system.

How long does it take?+

It depends on the size of the system and the data. After the analysis you receive a plan with phases and timelines.

What happens to the old data?+

We migrate what is needed for day-to-day work, and the rest stays in an archive for reference.
