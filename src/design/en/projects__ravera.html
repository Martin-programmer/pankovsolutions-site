The task

Ravera makes parts and press moulds from customer drawings. Every order starts with an enquiry and a drawing, goes through a quote and reaches production. Enquiries, quotes and drawings lived in emails and on individual computers, with no overall view of sales.

Drawings, 3D models and machine programs are the company’s most valuable asset, and important data also sat on an external drive. One broken disk or a virus could stop work for days. So the project covered three things at once: sales, security and backups.

Automatic backups that a virus can’t delete

We started with a plan: which data matters, which computer it is on, how often it is backed up and how long it is kept. The plan is signed by both sides, and the system carries it out on its own.

  • 5 workstations and the accounting database are backed up 4 times per working day
  • The CRM system and the file cloud are backed up every night
  • An encrypted copy in another EU data centre every night
  • Computers can only add backups, never delete them
  • Backup integrity checked every week
  • 6 months of history and a test restore carried out
  • Proxmox Backup Server
  • PBS Plus
  • Backblaze B2
  • AES-256

The biggest challenges

Three systems, one deadline

The CRM, security and backups had to be ready, tested and with a trained team within 45 days. We built them on a shared foundation on one virtual server in the EU, so they share login, monitoring and backups instead of being three separate islands.

Backups ransomware can’t destroy

If a virus encrypts a computer in the office, it must not be able to reach the backups. Computers are only allowed to add new backups, old ones are removed only by the server, and the off-site copy is with a different provider.

One login for everything

Instead of separate passwords for the CRM, backups, cloud and security console, staff log in with one profile and a code from their phone. When someone leaves, their access is stopped in one place.

No new hardware and no new licences

The solution works with the existing computers and network equipment and is fully open source. Ravera pays no annual licences, and the data and settings are theirs, in open formats.
