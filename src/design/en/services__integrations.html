What an integration is

An integration is an automatic connection between two programs. When something happens in one, for example a new order, the other knows immediately and does its part, without anyone copying data.

Most companies use several programs that are good individually but don’t talk to each other. The result is hours of manual re-typing and errors discovered too late.

Without integrations

  • Orders are re-typed into the ERP
  • Waybills are written by hand
  • Stock levels on the website are wrong
  • Invoices are entered twice
  • Payments are reconciled by hand
  • Errors with every copy

With integrations

How we approach it

A good integration is invisible. It works without anyone thinking about it, and when something goes wrong, everyone knows right away.

Process first

We describe which data needs to move, from where, to where and when, before writing any code.

Official APIs

We use the systems’ official programming interfaces, not fragile workarounds.

Ready-made modules when they exist

If there is a reliable ready-made module for the connection, we use it. We write our own only when needed.

Log and notifications

Every event is recorded, and if there is an error, the responsible person gets a notification.

Retries

If a system temporarily doesn’t respond, the integration tries again without losing data.

Security

Access keys are stored securely, and each connection has only the permissions it needs.

Frequently asked questions

Can’t find an answer? Call +359 877 944 224.

Can you connect our two programs?+

Almost always, if at least one of them has a programming interface (API) or a way to exchange files. We check this at the consultation.

What happens if one system goes down?+

The integration keeps the events and retries when the system comes back. If the problem lasts, it sends a notification.

Do we have to replace our software?+

No. The goal of an integration is for the software you already use to work together.

How much does an integration cost?+

It depends on the systems and the volume of data. If there is a reliable ready-made module, it is faster and cheaper. After the analysis you receive a fixed price.

Who maintains the integration?+

We do, as part of support. When a system is updated and changes something, we adapt the connection.

Do you work with accounting software?+

Yes, by exchanging data in the format the accountant’s software accepts. We check the options for the specific program.
